Reparación

El notebook lee game_info_cleaned.parquet con Spark (474.417 filas, 27 columnas), lo convierte a pandas y exporta game_info_cleaned.csv. La entrada no es CSV: no configura encoding, separador ni na_values.

La columna «Por qué» explica el efecto técnico de cada decisión; el notebook no documenta una justificación textual por variable.

Variable(s)Decisión del notebookPor qué / efecto
slug, name, website, platforms, developers, genres, publishers Reemplazar la cadena vacía exacta '' por NaN. Hace que las celdas vacías se reconozcan como faltantes en la auditoría isna(), en vez de contarlas como texto presente. No rellena ni elimina la fila.
released pd.to_datetime(errors="coerce"). Permite tratar el campo como fecha (por ejemplo, agrupar por año); fechas inválidas pasan a NaT, sin inventar una fecha.
updated pd.to_datetime(errors="coerce"). Normaliza el tipo temporal; valores no parseables pasan a NaT en lugar de interrumpir el parseo.
rating pd.to_numeric(errors="coerce"). Permite cálculos y resúmenes numéricos; entradas inválidas pasan a NaN.
metacritic pd.to_numeric(errors="coerce"). Permite comparar y resumir puntajes; entradas inválidas pasan a NaN, no se imputan.
playtime pd.to_numeric(errors="coerce"). Permite operar con tiempo de juego como cantidad; entradas inválidas pasan a NaN.
id, tba, rating_top, achievements_count, ratings_count, suggestions_count, game_series_count, reviews_count, esrb_rating, added_status_yet, added_status_owned, added_status_beaten, added_status_toplay, added_status_dropped, added_status_playing Sin transformación adicional en la celda de limpieza. 07 · modeloDePrediccionEric2.ipynb

Modelos de predicción

Clasificación de plataforma a partir de nombres y texto de proyectos. La variable objetivo se asignó mediante reglas, así que las métricas evalúan cuánto reproduce el modelo esas etiquetas automáticas.

y · objetivo

categoria_plataforma, creada con reglas sobre texto_registro: Desktop Standalone (257,583), Web/HTML5 (111,748), Prototipo / Assets (104,803) y Multiplataforma (267).

X · variables incluidas

slug_limpio (TF-IDF de caracteres, n-gramas 2–5) y tres métricas: longitud_slug, cantidad_palabras y tiene_guion.

Variables excluidas

texto_registro se usa para construir y, no entra en X. No se incluyen las demás columnas originales; el transformador descarta cualquier columna restante (remainder="drop").

Partición y modelo

train_test_split(test_size=0.30, random_state=42, stratify=y): 70% entrenamiento y 30% test, conservando proporciones de clase. El clasificador final es LinearSVC(class_weight="balanced").

Baseline · clase mayoritaria

El notebook no calcula baseline. Como referencia derivada, predecir Desktop Standalone para todo el test da 77,275 / 142,321 = 54.30% accuracy y 17.59% F1 macro.

Resultado final en test

Accuracy: 57.33% · F1 macro: 59.14% · precision macro: 58.02% · recall macro: 60.50%. La accuracy supera el baseline derivado por 3.03 puntos porcentuales.

Límite: como y se generó por reglas a partir del texto, el resultado no confirma por sí mismo la plataforma real de cada proyecto.
